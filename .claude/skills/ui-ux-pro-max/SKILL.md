# UI/UX Pro Max — чеклист якості

Дрібниці, які найчастіше пропускають і через які інтерфейс виглядає саморобним.

## Іконки й візуал

| Правило | Робити | Не робити |
| --- | --- | --- |
| Без емодзі-іконок | SVG (Lucide / Heroicons / Simple Icons) | 🎨 🚀 ⚙️ як елементи UI |
| Стабільний hover | Перехід кольору / прозорості | `scale`, що зсуває лейаут |
| Правильні лого брендів | Офіційний SVG із Simple Icons | Вгадувати шлях контуру |
| Однаковий розмір іконок | Фіксований `viewBox 24×24`, `w-6 h-6` | Міксувати розміри |

## Взаємодія

| Правило | Робити | Не робити |
| --- | --- | --- |
| Курсор | `cursor-pointer` на всьому клікабельному, включно з картками | Лишати дефолтний курсор |
| Відгук на hover | Колір / тінь / рамка змінюються | Нічого не показувати |
| Переходи | `transition-colors duration-200` (150–300 мс) | Миттєво або >500 мс |
| Фокус | Видимий focus-стан для клавіатури | Знімати outline без заміни |

## Світла тема / контраст

| Правило | Робити | Не робити |
| --- | --- | --- |
| Скляна картка у світлій | `bg-white/80` і вище | `bg-white/10` — не видно |
| Текст у світлій | `#0F172A` | `#94A3B8` для основного тексту |
| Приглушений текст | не світліше `#475569` | `gray-400` і світліше |
| Рамки | `border-gray-200` у світлій | `border-white/10` — невидима |

Мінімум контрасту для тексту — 4.5:1. Перевіряти **обидві** теми перед здачею.

## Лейаут і відступи

- Плаваючий навбар — `top-4 left-4 right-4`, а не приклеєний до `0`.
- Контент враховує висоту фіксованих елементів — нічого не ховається під навбаром.
- Один `max-w-*` на весь екран, не міксувати ширини контейнерів.
- Адаптив перевіряти на 375 / 768 / 1024 / 1440. Горизонтального скролу на мобільному бути не може.

## Доступність

- `alt` у всіх картинок, `label` у всіх полів форми.
- Колір — не єдиний носій сенсу (додавати іконку/текст).
- Поважати `prefers-reduced-motion`.

## Чеклист перед здачею

- [ ] Немає емодзі замість іконок, набір іконок один
- [ ] Hover не зсуває лейаут, курсор правильний, перехід 150–300 мс
- [ ] Фокус видно з клавіатури
- [ ] Світла й темна теми перевірені: текст, рамки, прозорі поверхні
- [ ] Відступи від країв, нічого не під фіксованими елементами
- [ ] 375 / 768 / 1024 / 1440 без горизонтального скролу
- [ ] alt, label, `prefers-reduced-motion`

## Специфіка edge-journal

Кольори беремо з `T.*` (`src/lib/theme.js`), а не з палітри Tailwind із прикладів вище — там
`slate-*` лише як орієнтир контрасту. Світла тема живе в `src/lib/themes.js`; перевіряти обидві.
Іконки — `lucide-react`, анімації — `framer-motion` з `EASE`/`SPRING` із `theme.js`.

> Примітка: оригінальний скіл мав `scripts/search.py` з базою дизайн-систем.
> Скрипта тут немає — лишилися тільки правила.
